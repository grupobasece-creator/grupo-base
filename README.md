# Grupo BASE

Site institucional da Grupo BASE — estrutura, palco, som, luz, painel de LED e gerador para eventos em Fortaleza e no Nordeste.

## Como abrir localmente

Abra `index.html` no navegador. Não precisa instalar nada: o site é estático.

## Estrutura

```
index.html                 página principal
assets/css/styles.css      identidade visual
assets/js/main.js          menu mobile e formulário de orçamento
assets/img/                logo, capa social e portfólio
archive/                   versão original em um único arquivo
robots.txt
sitemap.xml
site.webmanifest
```

## Publicar

Envie a pasta inteira (exceto `archive/`) para Netlify, Vercel, GitHub Pages ou qualquer hospedagem estática.

Domínio: https://www.basece.com.br
